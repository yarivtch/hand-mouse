# עכבר יד (Hand Mouse)

שליטה במחשב עם תנועות היד מול מצלמת הרשת: עכבר, ציור ניאון זוהר על המסך בסגנון סרטוני ההסבר של IBM, מצב מצגת והקלטת הסבר. עובד ב-Windows ו-macOS, וגם ב-Linux.

## התקנה

1. צריך Python 3.10 ומעלה (הכי בטוח: 3.11 או 3.12). ב-Windows מורידים מ-python.org ומסמנים בהתקנה "Add Python to PATH".
2. שמים את כל הקבצים בתיקייה אחת.

### Windows

לוחצים פעמיים על `run_windows.bat`. בהפעלה הראשונה הוא יוצר סביבה וירטואלית בתיקייה `.venv`, מתקין לתוכה את התלויות ומפעיל. בפעמים הבאות הוא רק מפעיל.

### macOS ו-Linux

פותחים טרמינל בתיקייה ויוצרים סביבה וירטואלית (פעם אחת):

```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

הסביבה הווירטואלית שומרת את התלויות בנפרד משאר המחשב. זה חשוב כאן: ‏MediaPipe מביא איתו גרסה של OpenCV, והיא מתנגשת עם `opencv-python` אם הוא מותקן גלובלית. מאותה סיבה אל תתקין `opencv-python` בנוסף.

## הפעלה

ב-Windows: לחיצה כפולה על `run_windows.bat`. ב-macOS ו-Linux:

```
source .venv/bin/activate
python hand_mouse.py
```

להפעלה ידנית ב-Windows (למשל עם אפשרויות): `.venv\Scripts\activate` ואז `python hand_mouse.py`.
בהפעלה הראשונה הסקריפט מוריד את מודל זיהוי היד (כ-8MB) ושומר אותו ליד הקובץ.

נפתחים סרגל זכוכית צף בראש המסך וחלון מצלמה מעוגל בפינה (ראו `screenshot-draw.jpg` ו-`screenshot-board.jpg`).

- **הסרגל:** בצד שמאל בורר מצבים: עכבר, ציור ומצגת. כלי הציור (צבעים, צורות, לוח כהה) מופיעים רק במצב ציור ומצגת. אחריהם ביטול, ניקוי, צילום, הקלטה, חלון מצלמה, השהיה ויציאה. מעבר עם העכבר על אייקון מראה מה הוא עושה ואת הקיצור שלו.
- **לחיצה:** עם העכבר הרגיל, עם היד במצב עכבר, או במצב ציור ומצגת: מכוונים אל הכפתור (הוא מקבל מסגרת) וצובטים.
- **הזזה:** גוררים את הסרגל או את חלון המצלמה בעכבר. את חלון המצלמה מסתירים ומחזירים בכפתור המצלמה שבסרגל.
- **תווית מצב:** בפינת חלון המצלמה רואים את המצב הנוכחי, ונקודה ירוקה או כתומה (מושהה). כל מעבר מצב מקפיץ הודעה קטנה בתחתית המסך.

## מצב עכבר

- **הזזה:** מצביעים עם האצבע. הסמן הולך אחרי הנקודה שבין קצה האגודל לקצה האצבע, כך שהוא לא קופץ כשצובטים.
- **קליק שמאלי:** צביטה קצרה של אגודל ואצבע, ושחרור.
- **גרירה:** צובטים ומחזיקים כשליש שנייה, מזיזים ומשחררים.
- **קליק ימני:** צביטה של האגודל עם האצבע האמצעית.
- **גלילה:** אצבע ואמה זקופות וצמודות, מזיזים את היד למעלה או למטה.
- **עצירה במקום:** אגרוף.
- **השהיה והפעלה מחדש:** כף יד פתוחה ופרושה, בלי לזוז, כשנייה (טבעת כתומה מתמלאת בחלון המצלמה).

## מצב ציור

קווי ניאון זוהרים מעל כל מה שעל המסך. העכבר לא זז במצב הזה, ומה שמתחת ממשיך לעבוד כרגיל.

- **ציור:** צובטים אגודל ואצבע ומזיזים. פותחים את הצביטה כדי להרים את העט. הטבעת על המסך מראה איפה העט.
- **ביטול:** צביטה של האגודל עם האמה.
- **צבע הבא:** אצבע ואמה צמודות.
- **ניקוי הכל:** כף יד פתוחה בלי לזוז כשנייה. גם ניקוי אפשר לבטל.
- **לוח כהה:** כפתור "לוח" מחשיך את הרקע כמו לוח אור אמיתי.
- **צילום:** כפתור "צילום" שומר תמונה של המסך עם הציור.

כשחוזרים למצב עכבר הציור נשאר על המסך עד שמנקים אותו.

### צורות חכמות

כשמסיימים קו, ציור גס של עיגול, אליפסה, מלבן, משולש, קו ישר או חץ מתיישר לצורה נקייה. קווים ומלבנים כמעט ישרים מתיישרים לגמרי.
חץ אפשר לצייר בתנועה אחת (קו ואז ראש), או קו ומיד אחריו "V" קטן בקצה שלו.
כתב יד ושרבוטים נשארים כמו שציירת. ביטול ראשון מחזיר את הצורה למה שציירת ביד, ביטול נוסף מוחק אותה.
מכבים ומדליקים בכפתור "צורות".

## מצב מצגת

פותחים את המצגת (PowerPoint, Google Slides, Keynote או PDF) ועוברים למצב מצגת.

- **שקף הבא:** מחליקים יד פתוחה שמאלה. **שקף קודם:** ימינה.
- **מצביע לייזר:** מצביעים עם האצבע, ונקודה אדומה זוהרת הולכת אחריה.
- **סימון על השקף:** צובטים ומציירים. הסימון נמחק כשעוברים שקף.
- **מנוחה:** אגרוף.

החיצים נשלחים לחלון שבפוקוס, אז לוחצים פעם אחת על המצגת לפני שמתחילים.

## לוח נייר: ציור בטוש אמיתי על דף אמיתי

תוכנית נפרדת, `paper_board.py`. מציירים בטוש על דף לבן, מצלמה מסתכלת על הדף מלמעלה, והציור מופיע על המסך כקווי ניאון זוהרים מעל כל מה שפתוח. בלי צביטות ובלי ציור באוויר.

**מה צריך:** מצלמה שרואה את השולחן. הכי פשוט טלפון כמצלמת רשת (באייפון עם Mac זה מובנה; אחרת אפליקציה כמו Iriun או DroidCam), מונח על ערימת ספרים או חצובה כשהמצלמה פונה למטה.

```
python paper_board.py --camera 1
```

ב-Windows אפשר ללחוץ פעמיים על `run_paper_windows.bat` (הוא פותח את מצלמה 0; למצלמה אחרת מריצים ידנית עם `--camera 1`).

- **הדף:** דף לבן על שולחן כהה ממנו, כולו בתוך התמונה. בחלון המצלמה הקטן הדף מקבל מסגרת ירוקה כשהוא מזוהה, והנקודה מסמנת את הצד העליון שלו.
- **העט:** טוש או לורד, לא עט כדורי דק. טוש שחור יוצא בצבע הניאון שבחרת, וטושים צבעוניים שומרים על הצבע שלהם.
- **היד:** הקו מופיע על המסך כשהיד זזה ממנו, לא מתחתיה, כי המצלמה לא רואה דרך היד.
- **דף חדש:** מחליפים דף והציור מתנקה לבד.

מקשים (לוחצים קודם על חלון המצלמה): רווח מקפיא את הציור על המסך, B לוח כהה, R מסובב רבע סיבוב אם הציור יוצא על הצד, M תמונת ראי, K צבע הבא לדיו שחור, H הסתרה והצגה, Q יציאה.

אם קווים דקים לא נתפסים: `--threshold 0.85`. אם נתפסים צללים: `--threshold 0.7`.

## הקלטת הסבר

כפתור "הקלטה" מקליט את המסך עם הציורים, את המצלמה בעיגול בפינה הימנית התחתונה ואת המיקרופון. לוחצים שוב כדי לעצור, והסרטון נשמר כ-MP4.
הסרגל לא נכנס להקלטה ב-Windows. כדאי לא לצייר ממש בפינה הימנית התחתונה, כי שם העיגול של המצלמה.

תמונות והקלטות נשמרות בתיקייה `HandMouse` בתוך תיקיית התמונות (Pictures). אפשר לשנות עם `--out-dir`.

## קיצורי מקשים

| קיצור | פעולה |
|---|---|
| Ctrl+Alt+M | השהיה והפעלה |
| Ctrl+Alt+D | מצב ציור (ושוב חזרה לעכבר) |
| Ctrl+Alt+T | מצב מצגת (ושוב חזרה לעכבר) |
| Ctrl+Alt+Z | ביטול |
| Ctrl+Alt+C | ניקוי הציור |
| Ctrl+Alt+K | צבע הבא |
| Ctrl+Alt+B | לוח כהה |
| Ctrl+Alt+S | צילום מסך |
| Ctrl+Alt+R | התחלה ועצירה של הקלטה |
| Ctrl+Alt+P | הצגה והסתרה של חלון המצלמה |
| Ctrl+Alt+Q | יציאה |

כשחלון המצלמה בפוקוס: רווח השהיה, H הסתרה, D ציור, T מצגת, Q או Esc יציאה.

## כוונונים שימושיים

```
python hand_mouse.py --help
```

- `--mode draw` להתחיל ישר במצב ציור (או `present`).
- `--margin 0.25` תנועות יד קטנות יותר מכסות את כל המסך (ברירת מחדל 0.18).
- `--min-cutoff 0.8` סמן יציב יותר אם הוא רועד (קצת יותר השהיה).
- `--pen-width 1.5` קו עבה יותר.
- `--no-shapes` להתחיל עם צורות חכמות כבויות.
- `--swipe-distance 0.12` החלקה קצרה יותר מספיקה להעברת שקף, `--invert-swipe` הופך כיוון.
- `--no-mic` הקלטה בלי קול.
- `--anchor tip` הסמן הולך אחרי קצה האצבע עצמו.
- `--scroll-speed 60` גלילה מהירה יותר, `--invert-scroll` הופך כיוון.
- `--camera 1` מצלמה אחרת, `--no-preview` בלי חלון מצלמה, `--start-paused` להתחיל מושהה.
- `--classic` רק עכבר, בלי סרגל ובלי ציור (לא צריך PySide6).
- `--preview-width 240` חלון מצלמה קטן יותר (ברירת מחדל 300).

## macOS: הרשאות

בפעם הראשונה macOS יבקש אישורים. אם משהו לא עובד, פותחים **הגדרות מערכת > פרטיות ואבטחה** ומאשרים לאפליקציה שממנה הרצת (Terminal, iTerm או VS Code):

- **מצלמה** כדי לראות את היד.
- **נגישות** כדי להזיז את העכבר, ללחוץ ולשלוח חיצים במצגת.
- **ניטור קלט** כדי שקיצורי המקשים יעבדו.
- **הקלטת מסך** לצילום ולהקלטת הסבר (בלעדיה רואים רק את הרקע).
- **מיקרופון** לקול בהקלטה.

אחרי שמאשרים צריך לסגור ולפתוח מחדש את הטרמינל. ב-Mac הקיצורים הם Ctrl+Option.
אם הסקריפט קורס מיד בהפעלה ב-Mac, מריצים עם `--no-hotkeys` ומשתמשים בסרגל ובחלון המצלמה.
אם הורדת המודל נכשלת בשגיאת SSL, מריצים פעם אחת את `Install Certificates.command` מתיקיית Python שבתוך Applications.

## Linux

עובד בסשן X11 (ב-Wayland הזזת העכבר חסומה, אז בוחרים בכניסה "Ubuntu on Xorg" או דומה). השכבה השקופה צריכה שולחן עבודה עם קומפוזיטור, כמו ברוב ההפצות.
אם Qt מתלונן על xcb: `sudo apt install libxcb-cursor0`.

## טיפים

- תאורה טובה מלפנים ויד אחת בתמונה משפרות את הדיוק מאוד.
- כשהיד יוצאת מהתמונה הסמן נעצר, וגרירה או קו פתוחים משתחררים.
- עובד על המסך הראשי. למסך אחר אפשר לתת את הגודל ידנית, למשל `--screen 2560x1440`.

## הקבצים

- `hand_mouse.py` זיהוי היד, התנועות והשליטה בעכבר ובמקלדת. מכאן מריצים.
- `ui_kit.py` העיצוב: צבעים, גופן, אייקונים והכפתורים של הסרגל.
- `light_board.py` מה שעל המסך: שכבת הציור, הסרגל, חלון המצלמה וההקלטה.
- `shapes.py` זיהוי הצורות החכמות.
- `paper_board.py` לוח הנייר: תוכנית נפרדת שלא תלויה בשאר.
